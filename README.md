# universal-media
[universal-uniq.github.io/universal-media/](https://universal-uniq.github.io/universal-media/)

Universal Media — мощный онлайн-редактор изображений с конвертацией, сжатием, редактированием и водяными знаками. Всё работает в браузере через Canvas.

🎬 Universal Media
Универсальный инструмент для работы с изображениями прямо в браузере

✨ Возможности
🎯 Конвертер изображений
Поддержка форматов: PNG, JPG, WebP, BMP, GIF, HEIC

Экспорт в: PNG, JPG, WebP, SVG, ICO

Пакетная обработка до 10 файлов

Скачивание всех результатов одним ZIP-архивом

Отображение размера до и после конвертации

🗜 Сжатие изображений
Регулировка качества от 10% до 100%

Готовые пресеты: Соцсети (85%), Веб (75%), Макс. качество (95%), Сильное (50%)

Отображение процента сжатия

Пакетная обработка нескольких файлов

✏️ Редактор изображений
Обрезка с выделением области

Поворот на 90° и отражение

Фильтры: Черно-белый, Сепия, Неон, Винтаж

Регулировка яркости и размытия

Рисование кистью с настройкой цвета и толщины

Добавление текста с выбором шрифта

Библиотека стикеров (эмодзи)

История действий (Ctrl+Z) для 10 последних операций

💧 Водяной знак
Текстовый и графический режим

Настройка прозрачности, размера, поворота

Выбор позиции: Центр, Верхний левый, Нижний правый, Случайно

Мозаичное заполнение

Тень для лучшей читаемости

🎨 Дизайн
Цветовая схема: Чёрный + Фиолетовый

Glassmorphism: Стеклянные карточки с размытием

Неоновое свечение кнопок

Анимированный фон с парящими частицами

Тёмная/Светлая тема с переключателем

Адаптивность под все устройства

🚀 Технологии
Чистый JavaScript без сторонних библиотек

Canvas API для всех графических операций

FileReader API для загрузки файлов

Blob и URL.createObjectURL для работы с данными

JSZip (CDN) для создания ZIP-архивов

Google Fonts для типографики

📦 Установка и запуск
Локальный запуск
bash
# Клонируйте репозиторий
git clone https://github.com/your-username/universal-media.git

# Откройте index.html в браузере
cd universal-media
open index.html
GitHub Pages
Перейдите в настройки репозитория

В разделе "Pages" выберите ветку main

Нажмите "Save"

Сайт будет доступен по адресу: https://your-username.github.io/universal-media/
